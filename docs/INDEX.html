Architecture Philosophy
Go modular monolith with strict module boundaries. Each module owns its schema queries and service interface. No cross-module DB joins. Phase 2 extraction requires a rename, not a rewrite.
🛡
Security-First Design
Schema-per-tenant isolation from day one. PII masked before every LLM call. Audit log is INSERT-only at DB permission level. RBAC enforced in middleware, never in handlers. JWT RS256 with 1hr access + refresh rotation.
🧠
AI Governance
Provider-agnostic LLM router — swap Anthropic for OpenAI without code changes. Every AI inference in the Action Ledger. Human review gates on low-confidence outputs. Prompt registry versioned with human approval gates.
