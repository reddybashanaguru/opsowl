The Problem
Manual AML Operations Are an Examination Waiting to Happen.
Four problems every compliance team is either living with today — or one FIU-IND visit away from discovering.
📧
No Defensible Investigation Trail
Your investigation record is forwarded emails and Word documents. When the FIU-IND examiner asks for the evidence chain, you will not have one that holds up. Every WhatsApp message and spreadsheet used in the investigation becomes inadmissible.
REGULATORY RISK
Examiner observation → remediation plan → compounding scrutiny on repeat visits
✍️
Analysts Write Reports, Not Investigations
3–4 hours to write one STR narrative. Your best analysts spend 80% of their week on documentation and 20% on actual judgment. When throughput is capped, the alert queue grows faster than the team can close cases.
CAPACITY RISK
Alert queue grows → PMLA deadlines slip → compounding penalty exposure per missed filing
⏱️
Missed Deadlines With No Early Warning
PMLA requires STR filing within 7 days of forming suspicion. No system tracks when that clock started. No SLA dashboard. No escalation. A missed deadline is a regulatory finding — and PMLA penalties compound on repeat breaches.
COMPLIANCE RISK
7-day window missed → late filing notice → monetary penalty escalation on repeat
🤖
No Record of AI-Assisted Decisions
Your analysts already use ChatGPT to draft STR narratives. You have no log of what the AI wrote, whether a human reviewed it, or if the output was changed. RBI examiners will ask — and "we checked it manually" is not an answer.
AI AUDIT RISK
Uncontrolled AI + no review log → RBI/PMLA audit exposure on next FIU-IND examination

Responsible AI
AI That Assists — Not Decides.
16 guardrails enforced in code — not policy. PMLA & RBI compliant by design. Every AI decision logged, human-reviewed, and hash-sealed. Provable in front of any FIU-IND examiner.
🛡 Input Safety
What goes
into the AI
PII Masking Before LLM
pii_masker.py
Microsoft Presidio strips PAN, Aadhaar, mobile, email, IFSC, and bank account numbers before any text reaches the model. Token map held in memory only — never written to disk.
Prompt Injection Detection
agent.py · copilot.py
5 compiled regex patterns block "ignore previous instructions", "jailbreak", "disregard" and 3 more. HTTP 400 returned — LLM never called.
Internal Service Auth Gate
service_auth.py
All 9 AI endpoints require a server-side service token. Only the Go API can call the AI service — no external party, no browser, no direct API access possible.
Similarity Threshold Gate
rag.py:14
Minimum cosine similarity of 0.35 required. Below threshold → INSUFFICIENT_CONTEXT returned. No hallucinated answers.
🤖 Model Constraints
What the AI
is allowed to do
Read-Only Agent — Hardcoded
investigation_agent.py:42
System prompt: "Read-only access through tools only." Zero write-capable tools — enforced by tool design, not instruction. Cannot create, update, or delete any record.
INSUFFICIENT_CONTEXT Protocol
copilot.py:96
System prompt: "Respond with INSUFFICIENT_CONTEXT if context is missing." Intercepted server-side — hallucinations cannot leak through as an answer.
Mandatory Source Citations
copilot.py:120
Every Copilot response includes a citations[] array — each claim linked to its source document with similarity score. Every sentence verifiable.
Hard Agent Iteration Cap
investigation_agent.py:38
MAX_ITERATIONS = 10 — agent terminates unconditionally after 10 tool calls. Prevents runaway loops; partial answer emitted with a clear notice.
👁 Output Controls
What happens
after AI responds
Confidence Score on Every Output
ai/dto.go:87
Every AI decision returns a confidence_score (0.0–1.0) shown to the reviewer before approval and stored permanently in the audit log.
Human Review Gate — Mandatory
ai/dto.go:89
All AI outputs start as pending. A named human must approve, reject, or edit before any output advances. AI cannot self-approve.
Approved Findings Only for Narrative
narrative/service.go:253
Narrative reads only status = approved findings. Draft or rejected findings excluded. Blocked until 4-eye review on all findings is complete.
4-Eye on AI Narrative Output
narrative/service.go:293
Generator cannot approve their own narrative — enforced in backend code. A second named reviewer must sign off before the STR can be filed.
⛓ Audit & Accountability
Permanent
provable record
Full AI Decision Log
ai/repository.go:51
Every AI call persists: model, provider, full prompt, output, confidence, action type, case ID. Retained permanently — never purged.
Named Reviewer on Every Decision
ai/dto.go:91
reviewed_by and reviewed_at stored permanently on every AI log. "Who approved this?" — one query away for any FIU-IND examiner.
FIU-IND Audit Export (CSV)
ai/handler.go:285
Manager+ exports date-ranged CSV: model, confidence, review status, reviewer, timestamp. Purpose-built for FIU-IND examination and PMLA audit submissions.
PMLA Record-Keeping Permanence
ai/repository.go:51
Every AI log record retained permanently — never purged. Meets PMLA Section 12 record-keeping requirements. Queryable and exportable for FIU-IND examination on demand.
